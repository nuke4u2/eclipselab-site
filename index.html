Eclipse Lab

Eclipse Lab is a personal technology and home-automation lab for software, sensing, wildlife monitoring, astronomy, and related projects.

Home Automation Notifications

Home Automation Notifications sends automated event notifications for Eclipse Lab projects. Current uses include notifications from the Backyard Bird Labeller.

Google authorization is used only to send notification email through Gmail. The application requests the Gmail gmail.send scope. It does not request permission to read, modify, or delete Gmail messages.
